## 2. ในซองมีอะไรบ้าง (ลำดับที่แขกเจอ)

ซองนอก **133 × 184 มม.** ฝาแหลมลึก ~80 มม. กระดาษเท็กซ์เจอร์ 150–170 แกรม

1. **หน้าซอง** — WN ปั๊มนูนมุมซ้ายบน ชื่อแขกเขียนด้วยปากกา A2L (ไทย: ฟอนต์ Charm “เรียน คุณ…”, อังกฤษ: Pinyon Script) จาก mail merge `WN_Envelope_Front_MailMerge.docx` + `WN_Guest_List.xlsx`
2. **หลังซอง** — ครั่ง WN สีแชมเปญ Ø30 ปิดปลายฝา (สติกเกอร์จาก `print/inserts.html` หน้า 3 หรือครั่งจริงด้วยตราปั๊ม 3D `favors/stl/wn-wax-seal-stamp-*.stl`) *จังหวะแรกคือการหักครั่ง*
3. **ซับในซอง (liner)** — รูป pre-wedding ขาวดำโทนอุ่น ทำด้วย **WN Liner Maker** (ย่อรูปต่ำกว่า 100% ได้แล้ว ส่วนที่ไม่มีรูปเป็นสีกระดาษ) ใต้ฝามีข้อความ *We saved a seat for you* · ฉีดกลิ่นซิตรัสบาง ๆ ก่อนปิดซอง 1 วัน
4. **ชุดการ์ด** มัดด้วยแถบ vellum 45 × 290 มม. + ริบบิ้นไหม 12 มม. (Blush / Sage / Champagne ตามโต๊ะ) + ครั่งใบเล็ก Ø25
   - **การ์ดเชิญ 127 × 178 มม.** กระดาษ 600 แกรม ปั๊มนูนจม ทาขอบทองแชมเปญ (โรงพิมพ์) — ไฟล์ `print/out/WN_invitation_127x178_bleed3.pdf` ด้านหน้า: ชื่อ วันที่ สถานที่ · ด้านหลัง: กำหนดการ dress code ที่อยู่ QR เว็บ
   - **การ์ดดอกไม้ “With love”** (~100 มม. Epson + A2L ตัด) ด้านหลัง QR PromptPay ของขวัญ
   - **แท็กคาร์ทูช RSVP** ยึดด้วยหมุดผ่า ซ่อนสติกเกอร์ **NFC NTAG213 Ø25** เขียน URL `https://nuttagon.github.io/webapp/#rsvp` (เขียนด้วยแอป NFC Tools) — แตะแล้วเปิดเว็บ RSVP + หาโต๊ะ
5. **การ์ดที่นั่งส่วนตัว 85 × 55 มม.** (ตัวเลือก) ชื่อ + เลขโต๊ะ + กลุ่ม จาก `print/inserts.html` หน้า 1 — แขกรู้โต๊ะตั้งแต่ก่อนมางาน ลดคิวที่จุดลงทะเบียน
6. **ของชำร่วยชิ้นแรกในซอง**: พวงกุญแจหัวใจ WN หนา 4 มม. (`wn-keychain-heart.stl`) ร้อยริบบิ้นสีเดียวกับโต๊ะ + แท็ก 40 × 70 มม. “With love” — น้ำหนักรวมซอง < 50 กรัม ส่งไปรษณีย์ได้

**ลำดับการเปิด (เหมือนแกะของขวัญ 7 จังหวะ)**: เห็นชื่อตัวเอง → พลิกเจอครั่ง → หักครั่ง เปิดฝา เห็น liner และข้อความลับ → ดึงชุดการ์ดที่มัดริบบิ้น → แกะ vellum เห็นชื่อปั๊มนูนรับแสง → พลิกการ์ดดูรายละเอียด → เจอการ์ดดอกไม้ + พวงกุญแจ + แท็ก NFC

## 4. หน้างาน
- จุดลงทะเบียนหลังเนิน: iPad เปิด `index.html#seating` + ป้าย QR “หาโต๊ะ” · ประทับตราจอดรถ
- ป้ายเลขโต๊ะพิมพ์ 3D (`wn-table-number-*.stl`) โทน Ivory + ตัวเลข Champagne
- ของชำร่วยที่โต๊ะ: โต๊ะกลม = พิมพ์กดคุกกี้หัวใจ + การ์ดสูตร (ของชำร่วย “อบเองที่บ้าน”) · VIP = ถาดแหวนหัวใจ · โต๊ะเพื่อนที่ทำงาน = ที่วางโทรศัพท์ · ทุกโต๊ะมีฐานการ์ดชื่อหัวใจที่เอากลับได้
- Photobooth ปลายทางเดินเข้า: กรอบ #EternallyWN

## 5. งานที่ยังต้องทำ / ข้อมูลที่ยังว่าง
1. กรอก `assets/js/config.js`: ที่อยู่และลิงก์แผนที่บ้านเคียงสะหวัน, ที่จอดรถ, เบอร์ผู้ประสานงาน, PromptPay (สร้าง QR จริงด้วย `segno`/แอปธนาคาร แล้วแทน `assets/img/qr-gift.svg`), เรื่องราว 3 ข้อแรก, ปลายทาง RSVP
2. รายชื่อแขกจริง → `assets/js/guests.js` (รูปแบบ `["ชื่อ", โต๊ะ, "bride|groom"]`) และ `WN_Guest_List.xlsx` สำหรับหน้าซอง
3. เปิด GitHub Pages (branch `main`, root) ให้ URL `https://nuttagon.github.io/webapp/` ใช้งานจริง — QR ในการ์ดทุกใบชี้ URL นี้แล้ว
4. ยืนยันช่วงเวลากำหนดการกับออแกไนซ์ (ตอนนี้เป็นตัวอย่างจากผัง Garden Reception v3)
5. พิมพ์ทดสอบพวงกุญแจ 1 ชิ้นและหัวตราปั๊ม ตรวจความคมของโมโนแกรม (ถ้าตื้นไป เพิ่มความลึกสลักใน `generate.js`)
