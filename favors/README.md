## ตั้งค่าพิมพ์ที่แนะนำ (Bambu Studio)
- **วัสดุ**: PLA Matte สี Ivory / Bone white ให้โทนเดียวกับกระดาษซอง · สลักลายใช้ PLA สี Champagne gold หรือ Antique Rose ผ่าน AMS (เปลี่ยนสีที่ความสูง = ความลึกสลัก)
- **Layer**: 0.2 มม. (หัวตราปั๊มและพวงกุญแจใช้ 0.12 มม. ให้ลายคม) · **Infill** 15% gyroid · **ผนัง** 3 เส้น
- **Ironing** เปิดที่ผิวบน (top surface) ของพวงกุญแจ ถาด และฐานการ์ด จะได้ผิวเรียบเหมือนกระดาษ
- ไม่ต้องใช้ support ทุกชิ้น · ด้ามตราปั๊ม: ลูกกลมด้านบนลาดพอที่จะพิมพ์ได้โดยไม่ต้องรอง
- พวงกุญแจ 30 ชิ้นต่อแผ่น: ใช้ “Arrange” ใน Bambu Studio แล้วพิมพ์แบบ by-layer

## เปลี่ยนสีลายด้วย AMS (ตัวอย่างพวงกุญแจ)
สลักลึก 0.8 มม. จากผิวบน (z 3.2–4.0) · ตั้ง filament change ที่ layer สูง 3.2 มม. → ตัวหัวใจสี Ivory ลาย WN สี Champagne

## แก้แบบ
ทุกขนาดอยู่ในฟังก์ชันของ `generate.js` (เช่น `heart2d(44)` = ความกว้างหัวใจ) แก้แล้วรัน
```
npm install @jscad/modeling @jscad/stl-serializer
node favors/generate.js            # 8 ไฟล์หลัก
node favors/generate.js --all-tables   # เพิ่มป้ายโต๊ะ A, B, 1–30 ใน favors/stl/tables/
```
