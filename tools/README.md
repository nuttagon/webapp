# เครื่องมือ

- `WN_Liner_Maker.html` — สำเนาของ WN Liner Maker (ตัวที่ใช้งานจริงอยู่ที่ https://claude.ai/artifact/D47JoAB5jHEZufd85uTbzr เพราะปุ่มดาวน์โหลดไฟล์ทำงานเฉพาะใน Claude)
  - ซูมรูป 25–300% · สีพื้นรอบรูป · ยืดปลายแหลม liner · โหมด "liner เต็มตัวซอง" (ลึก = ความสูงซอง − 2 มม.)
  - วัดซองจริง: กว้าง × สูง (ตัวซอง) และ "ฝาลึก" = จากรอยพับถึงปลายแหลม
